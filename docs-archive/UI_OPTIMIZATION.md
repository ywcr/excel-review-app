# UI优化说明文档

## 🎨 优化内容

根据用户反馈，对图片检测结果的UI显示进行了以下优化：

---

## 1. 正常评分不再显示徽章

### 优化前
所有图片都显示可疑度徽章，包括：
- ✅ 正常 (0-20分) - 绿色徽章

### 优化后
**只显示有问题的图片徽章：**
- 🟡 可疑 (20-40分) - 黄色徽章
- 🟠 疑似异常 (40-60分) - 橙色徽章
- 🔴 高度可疑 (60+分) - 红色徽章

**代码逻辑：**
```tsx
{typeof result.suspicionScore === 'number' && 
 result.suspicionLevel && 
 result.suspicionLevel !== 'LOW' && (  // 只显示非LOW的
  <span>...</span>
)}
```

**优点：**
- ✅ 减少视觉噪音
- ✅ 聚焦问题图片
- ✅ 更符合用户预期

---

## 2. 可疑度标签改为具体问题描述

### 优化前
统一显示模糊的标签：
- "可疑 (32分)"
- "疑似异常 (45分)"
- "高度可疑 (72分)"

❌ **问题：** 用户不清楚具体是什么问题

### 优化后
**根据主要因素显示具体标签：**

| 检测到的因素 | 显示标签 | 示例分数 |
|-------------|---------|---------|
| 包含"截图" | 🖥️ 疑似截图 (38分) | 20-40 |
| EXIF时间/值异常 | 🔄 疑似伪造 (72分) | 60+ |
| 专业编辑软件 | ✏️ 疑似编辑过 (55分) | 40-60 |
| 罕见/非标准比例 | 📐 尺寸异常 (28分) | 20-40 |
| GIF格式 | 🎬 GIF动图 (42分) | 40-60 |
| 其他情况 | ⚠️ 图片异常 (XX分) | 通用 |

**代码实现：**
```tsx
{(() => {
  const factors = result.suspicionFactors || [];
  if (factors.some(f => f.includes('截图'))) {
    return `疑似截图 (${result.suspicionScore}分)`;
  }
  if (factors.some(f => f.includes('EXIF时间异常') || f.includes('EXIF值异常'))) {
    return `疑似伪造 (${result.suspicionScore}分)`;
  }
  if (factors.some(f => f.includes('编辑软件'))) {
    return `疑似编辑过 (${result.suspicionScore}分)`;
  }
  if (factors.some(f => f.includes('罕见比例') || f.includes('非标准比例'))) {
    return `尺寸异常 (${result.suspicionScore}分)`;
  }
  if (factors.some(f => f.includes('GIF格式'))) {
    return `GIF动图 (${result.suspicionScore}分)`;
  }
  return `图片异常 (${result.suspicionScore}分)`;
})()}
```

**优点：**
- ✅ 一目了然问题类型
- ✅ 快速定位问题
- ✅ 减少用户困惑

## 3. 调整标签显示顺序

### 优化后的显示顺序

#### 核心错误（最优先）
1. 🔴 **重复** - 红色背景，白色文字
2. 🌹 **存在边框** - 玫瑰红背景，白色文字

#### 次要问题
3. 🔴 **模糊** - 红色浅背景，红色文字

#### 兼容旧系统
4. 🟣 **疑似网图** - 紫色浅背景（仅在无新评分时显示）
5. 🟡 **疑似非手机拍摄** - 黄色浅背景（仅在无新评分时显示）
6. 🟡 **低像素** - 黄色浅背景（仅在无新评分时显示）

#### 新评分系统（最后）
7. 🎯 **具体问题标签** - 根据因素智能显示
   - 疑似截图 / 疑似伪造 / 疑似编辑过 / 尺寸异常 / GIF动图 / 图片异常

**代码结构：**
```tsx
<div className="flex flex-wrap gap-2">
  {/* 1. 核心错误：重复和边框 */}
  {duplicates && <span>重复</span>}
  {hasBorder && <span>存在边框</span>}
  
  {/* 2. 模糊 */}
  {isBlurry && <span>模糊</span>}
  
  {/* 3. 旧系统兼容（只在无新评分时显示） */}
  {webLikelihood >= 0.55 && !suspicionScore && <span>疑似网图</span>}
  {dimensionOK === false && !suspicionScore && <span>疑似非手机拍摄</span>}
  {isLowPixel && !suspicionScore && <span>低像素</span>}
  
  {/* 4. 新评分系统（只显示非正常的） */}
  {suspicionScore && suspicionLevel !== 'LOW' && (
    <span>具体问题标签</span>
  )}
</div>
```

## 4. 图片验证摘要优化

### 优化前
4列布局：
- 总图片数
- 模糊图片
- 重复组
- 正常图片

### 优化后
**5列布局，新增"可疑图片"统计：**

| 统计项 | 颜色 | 计算逻辑 |
|--------|------|---------|
| 总图片数 | 灰色 | 总数 |
| 模糊图片 | 红色 | isBlurry = true |
| 重复组 | 橙色 | duplicateGroups |
| **可疑图片** | **黄色** | **suspicionScore ≥ 20** |
| 正常图片 | 绿色 | 总数 - 模糊 - 重复 - 可疑 |

**可疑图片统计逻辑：**
```typescript
const suspicious = results.filter((r: any) => {
  // 新系统：可疑度 ≥ 20分
  if (typeof r.suspicionScore === 'number' && r.suspicionScore >= 20) {
    return true;
  }
  // 旧系统兼容：网图或尺寸问题
  if (!r.suspicionScore) {
    if (r.dimensionOK === false) return true;
    if (typeof r.webLikelihood === 'number' && r.webLikelihood >= 0.55) return true;
  }
  return false;
}).length;
```

**优点：**
- ✅ 一眼看出可疑图片数量
- ✅ 与新评分系统对应
- ✅ 更全面的统计维度

## 10. 技术实现要点

### 智能标签生成
```typescript
// 根据因素优先级匹配
const factors = result.suspicionFactors || [];
const priorityKeywords = [
  { keywords: ['截图'], label: '疑似截图' },
  { keywords: ['EXIF时间异常', 'EXIF值异常'], label: '疑似伪造' },
  { keywords: ['编辑软件'], label: '疑似编辑过' },
  { keywords: ['罕见比例', '非标准比例'], label: '尺寸异常' },
  { keywords: ['GIF格式'], label: 'GIF动图' },
];

for (const { keywords, label } of priorityKeywords) {
  if (keywords.some(kw => factors.some(f => f.includes(kw)))) {
    return `${label} (${score}分)`;
  }
}
return `图片异常 (${score}分)`;
```

### 条件渲染优化
```typescript
// 只显示非正常的评分
{suspicionLevel !== 'LOW' && <Badge />}

// 旧系统兼容显示
{!suspicionScore && webLikelihood >= 0.55 && <Badge />}
```
