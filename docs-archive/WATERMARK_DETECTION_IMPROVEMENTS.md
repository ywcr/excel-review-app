# 水印检测改进说明 v1.1

## 📌 改进背景

用户反馈：部分水印（如右下角、左中等位置）无法被检测到。

**原因分析：**
- 原方案只检测四角 + 底部中心（5个区域）
- 覆盖率约40%，遗漏了左右中间等常见水印位置

---

## ✨ 改进内容

### 1. 采用9宫格检测策略

从**5区域**扩展到**7区域**（外围一圈 + 底部中心）：

```
原方案（5区域）：           新方案（7区域）：
┌────────┬────────┬────────┐   ┌────────┬────────┬────────┐
│ ✓左上角│  ✗跳过 │ ✓右上角│   │ ✓左上角│  ✗跳过 │ ✓右上角│
├────────┼────────┼────────┤   ├────────┼────────┼────────┤
│ ✗跳过  │  ✗跳过 │  ✗跳过 │   │ ✓左中  │  ✗跳过 │ ✓右中  │ ← 新增
├────────┼────────┼────────┤   ├────────┼────────┼────────┤
│ ✓左下角│ ✓底部  │ ✓右下角│   │ ✓左下角│ ✓底部  │ ✓右下角│
└────────┴────────┴────────┘   └────────┴────────┴────────┘

覆盖率：40% → 70%
性能影响：+30%
```

### 2. 扩大底部中心区域

```javascript
// 之前：底部15%区域
centerBottom: {
  height: 15%
}

// 现在：底部25%区域
centerBottom: {
  height: 25%  // 覆盖更多底部水印
}
```

### 3. 降低检测阈值

提高检测灵敏度，减少漏检：

```javascript
// 之前的阈值
WATERMARK_EDGE_THRESHOLD: 30
WATERMARK_CONTRAST_THRESHOLD: 40
WATERMARK_MIN_TEXT_COMPLEXITY: 15

// 优化后的阈值
WATERMARK_EDGE_THRESHOLD: 25         // ↓降低16.7%
WATERMARK_CONTRAST_THRESHOLD: 35     // ↓降低12.5%
WATERMARK_MIN_TEXT_COMPLEXITY: 12    // ↓降低20%
```

## 🗺️ 检测区域详细说明

### 7个检测区域

```javascript
1. topLeft (左上角)
   - 位置: (0, 0)
   - 尺寸: 15% × 15%
   - 用途: 检测版权声明、Logo

2. topRight (右上角)
   - 位置: (85%, 0)
   - 尺寸: 15% × 15%
   - 用途: 检测平台Logo、标识

3. leftMiddle (左中) ★新增★
   - 位置: (0, 40%)
   - 尺寸: 15% × 20%
   - 用途: 检测侧边水印、Logo

4. rightMiddle (右中) ★新增★
   - 位置: (85%, 40%)
   - 尺寸: 15% × 20%
   - 用途: 检测侧边水印、Logo

5. bottomLeft (左下角)
   - 位置: (0, 85%)
   - 尺寸: 15% × 15%
   - 用途: 检测来源标注、署名

6. bottomRight (右下角)
   - 位置: (85%, 85%)
   - 尺寸: 15% × 15%
   - 用途: 检测摄影师署名、网站Logo

7. centerBottom (底部中心) ★扩大★
   - 位置: (35%, 75%)
   - 尺寸: 30% × 25%（原15%）
   - 用途: 检测居中水印、版权声明
```

```typescript

WATERMARK_MIN_TEXT_COMPLEXITY: 14,
```

**如果漏检率高（明显水印未检测到）：**
```typescript

WATERMARK_CONTRAST_THRESHOLD: 32,
WATERMARK_MIN_TEXT_COMPLEXITY: 10,
```

## ⚠️ 注意事项

### 1. 误报率可能略微上升

由于检测范围扩大和阈值降低，可能会将以下情况误判为水印：
- 照片边缘的复杂细节（如树叶、建筑）
- 人物照片中的衣服图案
- 自然景物的纹理

**解决方案**：
- 查看置信度：<50%的可能是误报
- 人工复核高疑似图片
- 根据实际情况调整阈值

### 2. 性能影响

- 检测时间增加约30%（仍在100-130ms，可接受）
- 如果处理大量图片（>200张）可能略慢
- 可考虑使用Web Worker并行处理

### 3. 中心区域仍未覆盖

如果水印位于图片正中心：
```
┌────────┬────────┬────────┐
│ ✓      │  ✗     │   ✓    │
├────────┼────────┼────────┤
│ ✓      │  ❌中心 │   ✓    │ ← 仍未覆盖
├────────┼────────┼────────┤
│ ✓      │  ✓     │   ✓    │
└────────┴────────┴────────┘
```

**理由**：
- 中心区域容易误判正常内容（人脸、主体物）
- 水印很少位于正中心（会影响观看）
- 如确实需要，可以单独添加中心区域检测

## 🔮 后续优化方向

### Phase 1.2：智能区域选择
根据图片内容智能选择检测区域：
- 如果检测到人脸 → 跳过人脸区域
