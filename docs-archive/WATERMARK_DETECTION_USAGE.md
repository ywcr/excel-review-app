# 水印检测功能使用文档

## 📖 功能简介

水印检测是图片可疑度评分系统的一部分,用于自动识别图片中的水印/Logo,帮助判断图片是否来自网络而非用户原创拍摄。

### 适用场景
- ✅ **医院拜访照片审核**：检测是否使用网络图片冒充现场拍摄
- ✅ **活动照片审核**：验证照片真实性
- ✅ **资料提交审核**：确保照片来源合法

---

## 🎯 检测能力

### 可以检测的水印类型
1. **边角文字水印** ✅
   - 位于图片四角的文字水印（如版权声明、网站名称）
   - 位于底部中间的居中水印
   - 检测准确率：**约80-85%**

2. **高对比度Logo** ✅
   - 平台Logo（如微博、小红书、抖音）
   - 商业Logo（如淘宝、京东）
   - 检测准确率：**约70-75%**

### 无法检测的水印类型
1. **嵌入式隐形水印** ❌
   - 通过频域技术嵌入的不可见水印
   - 需要专业工具才能检测

2. **图片中心的水印** ❌
   - 当前只检测边缘区域（图片各边15%）
   - 未来版本可能支持

3. **极低对比度水印** ❌
   - 与背景颜色非常接近的水印
   - 可能被误判为正常内容

## 📊 评分规则

水印检测在可疑度评分系统中占 **0-15分**：

| 检测结果 | 分数 | 说明 |
|---------|------|------|
| 3个及以上区域有水印 | 12分 | 高度可疑（如四角+底部都有） |
| 2个区域有水印 | 8分 | 中度可疑（如左上+右下） |
| 1个区域有水印 | 5分 | 低度可疑（如仅右下角） |
| 高置信度（>80%） | +3分 | 额外加分 |
| 低置信度（<50%） | -2分 | 减分避免误判 |

### 置信度说明
系统会计算水印的置信度（0-100%），综合考虑：
- **边缘强度**：水印文字的清晰度
- **对比度**：水印与背景的差异
- **纹理复杂度**：是否有类似文字的笔画特征


如果需要调整检测灵敏度，可以修改配置文件：

### 提高灵敏度（检测更多水印，但可能误报）
```typescript
// src/lib/imageProcessor.ts

  WATERMARK_EDGE_THRESHOLD: 25,     // 降低（默认30）
```

## 🚨 常见问题

### Q1: 为什么正常照片被误判有水印？
**可能原因：**
- 照片角落有复杂的背景（如建筑细节、树叶）
- 照片边缘有高对比度的元素（如门框、窗户）

**解决方案：**
1. 查看置信度：如果<50%，可能是误报
2. 调整检测阈值（提高阈值可降低误报）
3. 人工复核：结合其他维度（如EXIF、尺寸）综合判断

### Q2: 为什么明显的水印没有被检测到？
**可能原因：**
- 水印位于图片中心（当前只检测边缘15%区域）
- 水印对比度过低（与背景颜色接近）
- 水印是透明的（透明度检测功能未实装）

**解决方案：**
1. 检查是否位于检测区域外
2. 手动标注该图片
3. 提交反馈以改进算法

### Q3: 如何禁用水印检测？
目前水印检测是自动启用的，如需禁用，可以：

**方法1：UI筛选**
- 取消勾选"显示水印"筛选器

**方法2：代码修改**（不推荐）
```typescript
// src/lib/imageProcessor.ts
async detectWatermark(imageData: Uint8Array) {
  // 直接返回无水印
  return {
    hasWatermark: false,
    watermarkRegions: [],
    watermarkConfidence: 0,
  };
}
```

### Q4: 检测速度慢怎么办？
水印检测已经过优化，但如果仍然慢：

1. **降低最大处理尺寸**
   ```typescript
   WATERMARK_MAX_SIZE: 600, // 默认800
   ```

2. **检查图片数量**
   - 单次处理超过100张图片时会较慢
   - 建议分批上传

3. **检查设备性能**
   - 低配设备可能需要更长时间
   - 建议使用Chrome浏览器
