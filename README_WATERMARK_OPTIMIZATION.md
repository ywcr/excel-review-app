## 🎯 关键技术突破

### 突破 1: 数据驱动优化 ⭐⭐⭐⭐⭐

**传统方法**：凭经验设置阈值  
**我们的方法**：

1. 分析 8 张真实水印图片特征
2. 确定特征范围（边缘 0.51-24.04）
3. 基于范围设置阈值（5）
4. 测试验证（100%召回率）

**结果**：准确、可靠、可解释

### 突破 2: 位置模式识别 ⭐⭐⭐⭐⭐

**发现**：

- 62.5% 水印在底部 3 区域
- 12.5% 水印在 4 个角落
- 水印有明显位置偏好

**创新点**：

- 不仅检测特征，还识别模式
- 匹配模式 → 加成分数
- 提高真假区分度

**效果**：真实水印平均 +9.7 分

### 突破 3: 异常高值检测 ⭐⭐⭐⭐

**发现**：某些误报置信度 90，超过所有真实水印（27-51）

**创新点**：

- 识别异常高置信度
- 不符合常见模式 → 降级
- 防止图片内容被高估

**效果**：减少 certain 级别误报
