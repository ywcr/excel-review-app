# 水印检测优化总结

## 📊 问题诊断

### 测试对比数据

| 指标 | 独立工具 (91.86%) | Excel验证 (25.51%) | 变化 |
|------|-------------------|-------------------|------|
| 频域 (frequency) | 0.00 | 19.47 | +19.47 |
| **梯度 (gradient)** | **121.86** | **3.11** | **-97%** ⚠️ |
| 纹理 (texture) | 0.00 | 100.00 | +100 ⚠️ |
| 颜色 (colorChannel) | 24.93 | 0.10 | -99.6% |
| **区域 (region)** | **86.47** | **0.00** | **-100%** ⚠️ |
| 透明度 (alpha) | 0.00 | 0.00 | 0 |

### 核心发现

1. **Excel压缩确实发生了**
   - 尽管图片尺寸相同 (816×459)
   - 但质量压缩导致主要特征严重损失
   - 梯度下降 97%，区域特征完全消失

2. **纹理检测误判**
   - 从 0 飙升到 100
   - 压缩伪影被误判为水印纹理特征
   - 这是最严重的问题

3. **主力特征失效**
   - 梯度和区域本应是主要水印指标
   - 但在压缩后几乎完全失效

## 🎯 建议策略

### 方案 A: 接受现状 (推荐)
- **阈值**: 保持 25% 或提高到 30%
- **分级显示**: 
  - 25-34%: "可疑水印" (suspicious)
  - 35-49%: "可能有水印" (likely)
  - ≥50%: "确定有水印" (certain)
- **用户提示**: "Excel压缩可能影响水印检测准确度"

### 方案 B: 降低阈值 (不推荐)
- **风险**: 降到 15% 会产生大量误报
- **原因**: 正常图片也可能达到 15-20% 置信度
- **后果**: 用户信任度下降

### 方案 C: 要求用户提供原图 (可选)
- 让用户上传原始图片单独验证
- 作为Excel验证的补充
- 显示两个置信度对比

## 🚫 不要做的事

1. ❌ **不要盲目降低阈值到很低值 (<20%)**
   - 会产生大量误报
   - 降低系统可信度

2. ❌ **不要试图"恢复"Excel压缩损失的信息**
   - 信息已经物理丢失
   - 无法恢复

3. ❌ **不要对所有图片使用相同的检测策略**

   - 考虑压缩程度
