# 拜访时长格式 - 快速参考

## 📋 一句话说明
拜访时长支持纯数字、带单位（中英文）、小时分钟复合等多种格式。

---

## ✅ 有效格式

### 数字格式
```
60        → 60分钟 ✓
100       → 100分钟 ✓
60.5      → 60.5分钟 ✓
```

### 中文单位
```
60分钟     → 60分钟 ✓
60 分钟    → 60分钟 ✓
90分       → 90分钟 ✓
1小时      → 60分钟 ✓
1.5小时    → 90分钟 ✓
2时        → 120分钟 ✓
```

### 英文单位
```
60min      → 60分钟 ✓
90mins     → 90分钟 ✓
60 minutes → 60分钟 ✓
1hour      → 60分钟 ✓
2hours     → 120分钟 ✓
1.5h       → 90分钟 ✓
```

### 复合格式
```
1小时30分钟  → 90分钟 ✓
2小时15分钟  → 135分钟 ✓
1时30分      → 90分钟 ✓
1h30m        → 90分钟 ✓
```

---

## ❌ 无效格式

```
分钟60       ✗ 单位在前
abc          ✗ 非数字
-60          ✗ 负数
60个小时     ✗ 不支持的单位
(空白)       ✗ 空值
```

## 💡 推荐用法

**最简单** → 直接写数字  
```
60
100
```

**最清晰** → 带单位  
```
60分钟
100分钟
```

**最直观** → 用小时  
```
1小时
1.5小时
2小时
```

---

## 🎯 典型场景

### 药店拜访 (≥60分钟)
✓ `60` `60分钟` `1小时` `70分钟` `1.5小时`  
✗ `59分钟` `30` `0.5小时`

### 医院拜访 (≥100分钟)
✓ `100` `100分钟` `120分钟` `2小时` `1时40分`  
✗ `99分钟` `1.5小时` `90`

---

## 🔍 快速检查

**是数字？** → ✓ 直接使用  
**有"分钟"、"小时"？** → ✓ 自动识别  
**有"min"、"hour"？** → ✓ 自动识别  
**有"小时+分钟"？** → ✓ 自动计算  
**其他情况？** → ✗ 可能无效
