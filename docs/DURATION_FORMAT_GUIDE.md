# 拜访时长填写格式指南

## 概述

系统现在支持多种拜访时长填写格式，您可以根据个人习惯选择最方便的方式。

## 支持的填写格式

### ✅ 方式1：纯数字（推荐）
最简单直接，数字代表分钟数。

**示例：**
- `60` → 表示60分钟
- `100` → 表示100分钟
- `120` → 表示120分钟

### ✅ 方式2：带中文单位
更加清晰明确，适合习惯中文的用户。

**分钟格式：**
- `60分钟`
- `60 分钟` （有空格也可以）
- `90分` （简写）

**小时格式：**
- `1小时` → 自动转换为60分钟
- `1.5小时` → 自动转换为90分钟
- `2时` → 自动转换为120分钟

### ✅ 方式3：带英文单位
支持英文单位，方便国际化场景。

**分钟格式：**
- `60min`
- `90mins`
- `60 minutes`

**小时格式：**
- `1hour` → 自动转换为60分钟
- `2hours` → 自动转换为120分钟
- `1.5h` → 自动转换为90分钟

### ✅ 方式4：复合格式
适合需要同时表示小时和分钟的情况。

**示例：**
- `1小时30分钟` → 90分钟
- `2小时15分钟` → 135分钟
- `1时30分` → 90分钟
- `1h30m` → 90分钟
- `1 小时 30 分钟` → 90分钟

## 各任务类型的时长要求

| 任务类型 | 最低时长要求 | 推荐填写示例 |
|---------|-------------|-------------|
| 药店拜访 | 至少60分钟 | `60`、`60分钟`、`1小时` |
| 等级医院拜访 | 至少100分钟 | `100`、`100分钟`、`1.5小时` |
| 科室拜访 | 至少100分钟 | `100`、`100分钟`、`2小时` |
| 基层医疗机构拜访 | 至少100分钟 | `100`、`100分钟`、`1小时40分` |
| 民营医院拜访 | 至少100分钟 | `100`、`120分钟`、`2小时` |

## 常见问题

### Q1: 我可以使用小数吗？
**A:** 可以！支持小数，例如 `60.5` 或 `1.5小时`。

### Q2: 英文单位区分大小写吗？
**A:** 不区分！`MIN`、`min`、`Min` 都可以识别。

### Q3: 数字和单位之间可以有空格吗？
**A:** 可以！`60分钟` 和 `60 分钟` 都是有效的。

### Q4: 如果我输入的时长不够怎么办？
**A:** 系统会提示验证失败，例如药店拜访输入 `59分钟` 会提示"拜访有效时间不低于60分钟"。

### Q5: 我可以使用负数吗？
**A:** 不可以，负数会被视为无效格式。

## ❌ 无效格式示例

以下格式**不会被识别**，请避免使用：

- `分钟60` ❌ （单位在数字前面）
- `abc` ❌ （纯文本）
- `-60` ❌ （负数）
- `60个小时` ❌ （不支持的单位）

## 建议

- 🔥 **最简单**：直接填写数字，如 `60`、`100`
- 💡 **最清晰**：带单位填写，如 `60分钟`、`100分钟`
- ⏰ **最直观**：使用小时，如 `1小时`、`1.5小时`、`2小时`

选择最适合您的方式即可！
